# Плагин модерации Wiki в Discourse

Добавляет модерацию правок wiki с процессом одобрения/отклонения через очередь проверки Discourse.

## Как это работает

- Когда пользователь, не входящий в исключения, редактирует wiki-пост, изменение сохраняется как ожидающее и откатывается в посте.
- Для модерации создается элемент очереди проверки для одобрения или отклонения.
- Опциональные уведомления отправляются модераторам и/или автору правки.
- Сотрудники могут просматривать ожидающие правки в **Админ → Плагины → Модерация wiki**.
- Для сравнения доступен inline и side-by-side diff.

## Настройки

Все настройки находятся в **Админ → Настройки → Плагины → Модерация wiki**.

- `wiki_moderation_enabled`: включить модерацию правок wiki.
- `wiki_moderation_ignore_staff`: позволить сотрудникам редактировать без проверки.
- `wiki_moderation_exempt_groups`: группы, которые могут редактировать без проверки.
- `wiki_moderation_notify_moderators`: уведомлять модераторов о новых правках.
- `wiki_moderation_notify_authors`: уведомлять авторов правки об одобрении/отклонении.
